# Атом-Монитор

Адаптивный сайт-агрегатор открытых новостей атомной отрасли. Он показывает заголовки, даты, краткие описания и ссылки на оригинальные публикации. Полные тексты статей сайт не собирает.

## Запуск на компьютере

Нужен Python 3.10 или новее. В папке проекта выполните:

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`. Чтобы получить первую ленту, в другой вкладке терминала запустите:

```bash
python collector.py
```

Сборщик использует RSS/Atom-адреса, опубликованные самими источниками. Если `robots.txt` доступен, его правила соблюдаются; если файл временно недоступен, сборщик пробует только явно опубликованную RSS-ленту, но не переходит к HTML-сканированию. HTML-лента используется только когда её разрешает `robots.txt` и на странице есть размеченные `<article>` с датой, ссылкой и описанием. Страницы отдельных статей не загружаются. При временной ошибке источника новости из предыдущего сбора сохраняются до 60 дней и помечаются статусом источника; выдуманные материалы не добавляются.

## Публикация бесплатно на GitHub Pages

1. Создайте GitHub-репозиторий и загрузите файлы проекта в ветку `main`.
2. В настройках репозитория откройте **Settings → Pages** и выберите публикацию через **GitHub Actions**.
3. Запустите действие «Обновить новостную ленту» вручную во вкладке **Actions**. После первого сбора сайт получит актуальные данные.
4. Действие «Опубликовать сайт» развернёт страницу. Сбор RSS затем будет запускаться автоматически каждые шесть часов; новые данные сохраняются в `data/news.json` и попадают на сайт после публикации. На главной странице у каждого источника видно число материалов; если источник временно не отвечает, предыдущие свежие публикации остаются доступны.

Планировщик GitHub Actions может запускаться с задержкой при высокой нагрузке. Вручную запустить обновление можно в **Actions → Обновить новостную ленту → Run workflow**.

## Возможности

- поиск по заголовку, описанию и названию источника;
- фильтры по источнику, теме, периоду и языку;
- сортировка от новых публикаций к старым;
- выгрузка текущего списка результатов в CSV;
- автоматическое удаление повторов и ограничение срока хранения новостей;
- адаптация для телефонов и больших экранов.

Если адрес RSS-ленты конкретного издателя изменился, обновите список `feeds` в `collector.py`. Источники без доступной RSS/Atom-ленты пропускаются, чтобы не обходить ограничения сайтов и не собирать лишний контент.
